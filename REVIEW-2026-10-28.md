# Independent code/design review and follow-up

An independent GPT-6 Astra reviewer at high reasoning effort inspected only the
documents and code, without conversation history. The baseline passed 328 tests
and TypeScript checking. This note records findings and subsequent fixes.

## Findings addressed

- Historical finding: capture-slot allocation lost equality constraints across
  alternatives. That representation was subsequently removed by design: duplicate
  captures on a matching path are now errors; types contain no capture slots or
  Bind/Same operations. Field relationships belong in refinements.
- Refining UnionType or Any incorrectly stamped a new concrete space. Refinements
  now retain the base's transparent behavior and selected member interpretation.
- String-headed constructor patterns collided with string encoding. Descriptor
  emission now uses Apply/Fields for that reserved head.
- Failed candidates evaluated unnecessary defaults. Constructor heads short-circuit;
  supplied fields match before defaults; exhausted named-field states cannot
  continue into positional tails.
- Obsolete documentation claimed interpretations never affected identity and that
  descriptor-aware serialization was absent. Those claims were replaced in place.

The reviewer independently confirmed the original four fixes, then found a
nested-default residual and an Apply-body schema/decoder disagreement. Both now
have regression coverage: failed named states stop before positional scanning,
and Apply requires Fields/OpenFields as its argument body.

## Architecture progress and limits

The source-language schema uses recursive Pattern<T>, FieldPattern<P>, FieldPack<P>,
Data, and TypeDescription instead of an Expression placeholder. Quoted operator
heads are literal in the common pattern compiler. The schema describes structure;
binder scope, normalization, extra-label policy, and semantic checks remain decoder work.

Public type equality requires structural type-value trees, not matcher behavior
or host object/closure identity. Unsupported predicate/default environments report
E_VALUE_REPRESENTATION. Internal session keys remain for matching; they do
not define public equality.

The larger review concern remains: descriptions, executable patterns, syntax-derived
accessor metadata, and unsupported internal descriptors have overlapping traversals.
Shared capture layout removes one duplication. Next is schema/decoder conformance
and a common semantic representation, before claiming a unified language grammar
or a self-hosted implementation.
