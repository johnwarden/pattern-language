# Approved decisions

These changes have been agreed in the project chat and are ready for PRs to turn
them into implementations. Commit these records and validated test-only contract
updates directly to master. An implementation PR can address one or more records,
revising existing tests or adding cases before changing implementation.

Move a record to `../implemented/` on master with links when actual tests capture its
decision. Todo tests still indicate unfinished language behavior. See [the lifecycle](../README.md).
