# Pending proposals

Store new proposals and motivating examples here. Discussion and clarification
happen in the project chat. Keep unknown behavior explicit; a plausible example
does not authorize an agent to choose its semantics.

After agreement, capture the settled content in `../approved/` and remove the
corresponding inbox file. Split unresolved content first. See [the lifecycle](../README.md).

Existing `tests/inbox/` drafts remain optional and runnable by explicit path
while they are triaged. Files here are proposal data outside default test discovery,
not evidence of executed coverage.
