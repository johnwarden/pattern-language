# Decisions captured in tests

Records move here when actual tests have been written or updated for their
decision. Each record links to the relevant test files/cases and conversion PR.

This records completion of the spec-to-test step. Tests may still be todo, so the
directory is not a claim that runtime implementation is complete. Follow the
linked executable contracts for status; retain prose as explanation and decision
history rather than a competing specification. See [the lifecycle](../README.md).
